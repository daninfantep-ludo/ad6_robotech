General Features (not in a particular order)
<ul>
 <li>1.- Different actor types: Main (PC/Villan), Lieutenant (foot), Swarm and Vehicle.</li>
 <li>2.- Main and Lieutenants can pilot vehicles, copying their skills, talents and elements and personal (not physical) equipment suites, as long as the player is owner of the actors. If the actor lacks of proficiency a red marker is show to remind that.</li>
 <li>3.- Naval vehicles without pilot implements Naval crew skill table. Lieutenants implement their set of skills based on carrer and minor/major/ultra. Also implemented veteran lieutenants.</li>
 <li>4.- Each weapon and equipment suite can specify how many hardware points the weapon represents. In naval, it can specify the amount of bank weapons.</li>
 <li>5.- Mark checkbox to roll with burnout cap. If not marked, Fatigue is spent automatically (Main)</li>
 <li>6.- A given roll can be selected as "fixed" or "declared" to be part of the turn structure. Upt to 3 rolls can be "fixed" at a time.</li>
 <li>7.- Synergy. If you fix a second roll in the same phase than the first one, it adds the successes and mark it as Synergy.</li>
 <li>8.- Assist mechanism. When fixed an assist roll, a pool is created from other players can take successes to improve their results, before getting their rolls fixed.</li>
 <li>9.- Combat tracker. Each fixed roll is shown in the combat tracker, roder by phase (color coded) and with successes and actions related to operate.</li>
<li>10.- Combat tracker. Push mechanism. You can spend fatigue to move up a fixed action. 1 per phase. 1 per action (2 if synergy)</li>
<li>11.- Automatic attack resolution. When attacking, attacker select successes (weapon selected at the moment of the attack roll). then defender select its defense. Upon confirmation the damage is calcualted considering </li>penetration, resist and other features. Damage is applied automatically if possible (not in main controlled mecha that are not basic)</li>
<li>12.- Dedefend mechanism. An actor can defend another one with their own successes in defend (or ops synergy phase)</li>
<li>13.- Concentrated fire. An actor can "borrow" successes from another ally. It doesn't validate the source scale or the destination scale (for now)</li>
<li>14.- Combat tracker. When all successes in an action has been spent, it disables, to help viewing what is left to resolve. Support or cinematic actions can be marked by gm as "done" with same visual effect.</li>
<li>15.- Advancing turn is rotative in the same round, so the token highlight can be used as a visual marker of sorts rather than the usual function.</li>
<li>16.- Upgrades. A type of item upgrade has been defined, to group things (bonuses, weapons, equipment suites, talents or elements), so it can be equiped to actors. The armored pack is an upgrade (in this system terms) but the GU-11 (weapon + equipment suite) is also an upgrade under this definition. Can be equipped and unequipped cleanly. It can also implement helpers like talents that provide elements without that being forgotten.</li>
<li>17.- Swarm definition besed on other actors / vehicles. Mixed swarms are allowed. Structure is calculated properly. The amount of Equipment Suites that can be used is left to the user.</li>
<li>18.- Swarms up to 25 units are presented in scene as a group of tokens, that moves as one and the number of units is drawn as the swarm unit total. </li>
<li>19.- A naval vehicle can be "equipped" in a main actor to mimic the actor is assisting in the vehicle use. It can be used for the copilot of a VEF-1, or to an officer to use the stations of a ship, without adding it to their sheet.</li>
<li>20.- Vehicles support different speed configurations selectable by the user. If thruster system is damaged the speed is recalculated</li>
<li>21.- Armor can be declared as a shield, with its own scale, and can be added to a vehicle (salamander's shield) or to a main/lieutenant (tedate shield)</li>
<li>22.- Implemented built though for races up to AtS. This bonuses are taken in consideration for damage calculation </li>
<li>23.- Implemented the different value per wound given species (zents, spherians, or zents with built though)</li>
<li>24.- Armors have resistances (energy, non melee, light damage, aoe damage) and weapons have damage descriptors (energy, melee)</li>
 <li>25.- Actors have config cogs, to specify built though talent, lion's roar, and vehicles being basic, using locations or using systems for full configuration</li>
<li>26.- Conclict actor implemented, for narrative conflicts</li>
<li>27.- Special combat flow for conflicts. The Conflict always attack, the players enganges with sinery or defense. </li>
<li>28.- Tiresian characters have clones with 3 wounds each. But system doesn't allocate damage automatically (todo). Mecha piloted by tiresian doesn't triple their structure (todo). Tiressian swarms doesn't consider the upgraded wounds/structure to the calculation (todo)</li>
 <li>29.- Fix bug: the clone adding is bounded to triumvirate career not tiresian species</li>
 <li>30.- When a triumvirate pilots a mecha, it structure is x3, when off or replaced /3</li>
 <li>31.- Fix bug: Replacing pilots kept concat pilot name with vehicle name</li>
 <li>32.- Implements automatic +1 armor when attacked with melee weeapon and the defender has equipped a parry tagged weapon</li>
 <li>33.- Implements incenidiary: a active effect that shows a flame in the token and in the visuals in the sheet. It adds +1 success per level cap 3 when a on fire unit is attacked. Control by active effects in foundry and in the character/lieutenant/swarm/vehicle sheet</li>
 <li>34.- Same with corrosive weapon tag. It last 1 round</li>
 <li>35.- Implements new weapon tag x2 damage to swarms, due to the shark's missiles (that are incenidary too)</li>
</ul>
