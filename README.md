General Features
 1.- Different actor types: Main (PC/Villan), Lieutenant (foot), Swarm and Vehicle.
 2.- Main and Lieutenants can pilot vehicles, copying their skills, talents and elements and personal (not physical) equipment suites, as long as the player is owner of the actors. If the actor lacks of proficiency a red marker is show to remind that.
 3.- Naval vehicles without pilot implements Naval crew skill table. Lieutenants implement their set of skills based on carrer and minor/major/ultra. Also implemented veteran lieutenants.
 4.- Each weapon and equipment suite can specify how many hardware points the weapon represents. In naval, it can specify the amount of bank weapons.
 5.- Mark checkbox to roll with burnout cap. If not marked, Fatigue is spent automatically (Main)
 6.- A given roll can be selected as "fixed" or "declared" to be part of the turn structure. Upt to 3 rolls can be "fixed" at a time.
 7.- Synergy. If you fix a second roll in the same phase than the first one, it adds the successes and mark it as Synergy.
 8.- Assist mechanism. When fixed an assist roll, a pool is created from other players can take successes to improve their results, before getting their rolls fixed.
 9.- Combat tracker. Each fixed roll is shown in the combat tracker, roder by phase (color coded) and with successes and actions related to operate.
10.- Combat tracker. Push mechanism. You can spend fatigue to move up a fixed action. 1 per phase. 1 per action (2 if synergy)
11.- Automatic attack resolution. When attacking, attacker select successes (weapon selected at the moment of the attack roll). then defender select its defense. Upon confirmation the damage is calcualted considering penetration, resist and other features. Damage is applied automatically if possible (not in main controlled mecha that are not basic)
12.- Dedefend mechanism. An actor can defend another one with their own successes in defend (or ops synergy phase)
13.- Concentrated fire. An actor can "borrow" successes from another ally. It doesn't validate the source scale or the destination scale (for now)
14.- Combat tracker. When all successes in an action has been spent, it disables, to help viewing what is left to resolve. Support or cinematic actions can be marked by gm as "done" with same visual effect.
15.- Advancing turn is rotative in the same round, so the token highlight can be used as a visual marker of sorts rather than the usual function.
16.- Upgrades. A type of item upgrade has been defined, to group things (bonuses, weapons, equipment suites, talents or elements), so it can be equiped to actors. The armored pack is an upgrade (in this system terms) but the GU-11 (weapon + equipment suite) is also an upgrade under this definition. Can be equipped and unequipped cleanly. It can also implement helpers like talents that provide elements without that being forgotten.
17.- Swarm definition besed on other actors / vehicles. Mixed swarms are allowed. Structure is calculated properly. The amount of Equipment Suites that can be used is left to the user.
18.- Swarms up to 25 units are presented in scene as a group of tokens, that moves as one and the number of units is drawn as the swarm unit total. 
19.- A naval vehicle can be "equipped" in a main actor to mimic the actor is assisting in the vehicle use. It can be used for the copilot of a VEF-1, or to an officer to use the stations of a ship, without adding it to their sheet.
20.- Vehicles support different speed configurations selectable by the user. If thruster system is damaged the speed is recalculated
21.- Armor can be declared as a shield, with its own scale, and can be added to a vehicle (salamander's shield) or to a main/lieutenant (tedate shield)
22.- Implemented built though for races up to AtS. This bonuses are taken in consideration for damage calculation 
23.- Implemented the different value per wound given species (zents, spherians, or zents with built though)
23.- Armors have resistances (energy, non melee, light damage, aoe damage) and weapons have damage descriptors (energy, melee)
